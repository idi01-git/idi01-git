# Master Raw Assets Archive

This directory contains the uncompressed, full-resolution master files (PNG, WebP, JPEG) for all artwork, banners, and social buttons delivered across the project. 

These master files are preserved here for archival and memory purposes. The live GitHub profile loads lightweight, optimized WebP assets for 100/100 performance, but links directly to these master files when clicked.
